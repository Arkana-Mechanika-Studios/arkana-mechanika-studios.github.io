Arkana Mechanika Labs · Restoration and research

Darklands Restoration Project

A long-term preservation and reverse-engineering project focused on understanding MicroProse’s 1992 RPG and rebuilding its behaviour in a faithful native C# engine. The project documents the original executable, data formats, runtime behaviour, and the tools used to verify the reconstruction.

  • Game preservation
  • Reverse engineering
  • Native C# engine
  • Technical documentation
