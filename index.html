Read the complete support policy
Which Unity versions are claimed for version 1.0?

Unity 6.0 LTS is the minimum. The release validation matrix targets Unity 6000.0, 6000.3, and 6000.5. Unity 2022.x and Unity 6.6 or newer are not claimed for version 1.0.

Which dependencies and render pipeline are required?

The Unity Input System is required. The default runtime UI uses UGUI and TextMesh Pro. The supplied demos and presentation assets are authored for URP.

Does the toolkit provide complete save-game management?

No. TBCS provides an extensible combat snapshot layer. File IO, save slots, campaign management, and any global transaction coordinator remain the consuming game’s responsibility.

Can the default systems be replaced?

Yes. Health, stats, actions, animation, inventory, catalogs, parties, persistence, UI services, and other integrations expose extension seams. Custom integrations still require project-specific implementation.

Does version 1.0 include multiplayer?

No. Networking and multiplayer synchronization are not included.

Does the package contain AI-assisted sample content?

Some default, sample, and demonstration art and audio began as generative-AI-assisted source material and was subsequently modified and integrated by Arkana Mechanika Studios. The package includes a detailed disclosure.
