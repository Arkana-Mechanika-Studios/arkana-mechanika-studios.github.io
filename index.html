The Toolkit

RPG Combat Toolkit (TBCS)

A modular framework for tactical, grid-based turn-based combat in Unity 6 — with 2D and 3D support, configurable action points, abilities, effects, inventory, stats, reactions, editor setup tools, default UGUI presentation, and three playable combat demonstrations.

🔧
A complete combat foundation

Turn flow, grids, movement, attacks, action points, abilities, effects, statuses, reactions, ready actions, projectiles, combat logging, and presentation modules are designed to work together while remaining replaceable.

🗺️
2D and 3D workflows

Dedicated 2D and 3D grid, cursor, overlay, animation, and ability-visualization paths share the same combat architecture. The package includes examples of both styles.

🎯
Modular targeting and abilities

Author targeting presets, validation rules, ranges, areas of effect, conditions, effects, projectiles, and visuals. Player, AI, preview, confirmation, reaction, and execution paths use the same runtime rules.

💾
Extensible combat snapshots

Capture and restore supported combat state through snapshot sources and adapters. TBCS provides the combat-state layer; file storage, save slots, campaign management, and any required all-or-nothing transaction layer remain part of the consuming game.

⚙️
Configure, validate, extend

Use guided setup for a new combat scene, validate project and scene prerequisites, configure supplied modules, and replace services or adapters without editing unrelated core systems.

Under the hood

Technical highlights

Built for developers who care about extension boundaries, serialization safety, and predictable setup.

Service-driven architecture

Shared contracts, service registration, per-actor services, factories, providers, adapters, and module registrars keep the runtime composable.

Granular assemblies

Shared, core, default, bootstrap, extension, editor, demo, and tooling responsibilities are separated through focused assembly definitions.

Modular abilities pipeline

Targeting, validation, execution, effects, reactions, AI use, previews, projectiles, and presentation are authored through reusable modules.

Action and reaction control

Normal actions, delayed actions, opportunity attacks, triggered reactions, and ready actions are handled through explicit queues and turn ownership.

Combat snapshot layer

Stock adapters cover turn order, actors, grid objects, health, action points, effects, inventory, equipment, and parties, with documented extension requirements.

Customer-facing diagnostics

The scene validator reports missing services, actors, factions, project requirements, EventSystem setup, TMP resources, URP, and tooltip configuration.

FAQ

Common questions

Which Unity versions are supported?

Version 1.0 requires Unity 6.0 LTS or newer. It has been validated with Unity 6000.0.79f1, 6000.3.8f1, and 6000.5.3f1. Unity 2022.x and Unity 6.6 or newer are not claimed for version 1.0.

Which packages and render pipeline are required?

The Unity Input System is required. The default runtime UI uses UGUI and TextMesh Pro. The supplied demos and presentation assets are authored for URP; projects using another render pipeline must provide and validate equivalent presentation assets.

Does it work with my existing save system?

TBCS provides an extensible combat snapshot layer, not file IO, save slots, or campaign save management. Connect the snapshot API to your storage solution. Restore is deterministic by subsystem, but it is not a single global transaction across every custom adapter.

Can I use it for a pixel-art 2D game?

Yes. The combat architecture supports 2D and 3D workflows. The package includes a 2D demonstration, 2D grid and visual components, while your own art and presentation remain under your control.

Can I replace the animation or other default systems?

Yes. Animation, health, stats, actions, item catalogs, parties, persistence, UI services, and other integrations expose extension seams. Third-party animation tools such as DOTween require an appropriate custom driver or adapter rather than being bundled integrations.

Does it include multiplayer?

No. Networking and multiplayer synchronization are not included in version 1.0.

Does the package contain AI-assisted content?

Some default, sample, and demonstration art and audio began as generative-AI-assisted source material and was subsequently modified and integrated by Arkana Mechanika Studios. It is not required by the toolkit architecture. The package includes a detailed Third-Party Notices disclosure, which will be mirrored in the Asset Store listing.

How do I get technical support?

Use the RPG Combat Toolkit support page for the official email channel, troubleshooting checklist, response target, required report information, and support scope.

When will it be on the Unity Asset Store?

Version 1.0 is in final validation and listing preparation. A public release date and price will be announced after the exact submission package has completed the remaining release gates.
